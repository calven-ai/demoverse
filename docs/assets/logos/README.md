# Logo tiles

Small rounded-tile icons used by the "Works with" strip in the root
[README](../../../README.md). Each file is a self-contained 40x40 SVG: a solid
tile plus a white glyph, so it stays legible on both the light and the dark
GitHub theme without a `<picture>` swap.

| File | Glyph source |
| --- | --- |
| `claude-code.svg`, `codex.svg`, `cursor.svg` | [Simple Icons](https://simpleicons.org) (CC0 1.0) |
| `salesforce.svg`, `hubspot.svg`, `google-drive.svg`, `slack.svg` | [Simple Icons](https://simpleicons.org) (CC0 1.0) |
| `agents-md.svg`, `by-hand.svg`, `your-own.svg` | drawn for this repo |

The brand names and marks belong to their respective owners. They appear here
only to say which tools Demoverse interoperates with. No affiliation or
endorsement is implied.
